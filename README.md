### 📚 &nbsp; libft
**Custom C standard library**

Reimplementing the entire libc from scratch — `memset`, `strlen`, `split`, linked lists and more. The foundation of everything else at 42.

![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)
![Makefile](https://img.shields.io/badge/Makefile-4B4B77?style=flat-square)

### 🖨️ &nbsp; ft\_printf
**printf reimplemented in C**

Full variadic function with format specifiers (`%s`, `%d`, `%x`...), edge cases, and no external libs. Because reinventing the wheel teaches you how wheels work.

![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)

[→ View repo](https://github.com/steevie-core/42cursus/tree/main/ft_printf)

### 📄 &nbsp; get\_next\_line
**Line-by-line file reading**

Read any file descriptor one line at a time with static buffers — handles multiple FDs, edge cases, and variable buffer sizes.

![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)

### 🖥️ &nbsp; Born2beRoot
**Linux system administration**

VM setup, disk partitioning, SSH hardening, UFW firewall, sudo rules, and a monitoring script — the unglamorous but essential side of dev.

![Linux](https://img.shields.io/badge/Linux-FCC624?style=flat-square&logo=linux&logoColor=black)

### ↕️ &nbsp; Push\_Swap — sorting with two stacks
**Algorithmic efficiency challenge**

Sort a stack using only two stacks and a constrained set of operations (`sa`, `pb`, `ra`...). The fewer moves, the better the grade. An exercise in thinking about complexity.
